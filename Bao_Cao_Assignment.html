LỜI MỞ ĐẦU

JavaScript là một trong những ngôn ngữ lập trình nền tảng và đóng vai trò linh hồn trong lĩnh vực phát triển Web hiện đại. Môn học Lập trình cơ sở với JavaScript (WEB1043 / WEB1404) tại FPT Polytechnic đã cung cấp cho sinh viên những kiến thức cốt lõi về cú pháp ngôn ngữ, cấu trúc dữ liệu mảng đối tượng, tương tác thao tác DOM (Document Object Model), xử lý sự kiện người dùng (Event Handling), kiểm tra biểu thức chính quy (Regex) và cơ chế lưu trữ dữ liệu bền vững ở trình duyệt thông qua Web Storage API (LocalStorage).

Dự án Website Bán Phụ Kiện Điện Tử TECHZONE được thực hiện nhằm tổng hợp, thực hành và hiện thực hóa toàn bộ các kỹ năng lập trình trên vào một bài toán thực tiễn: Xây dựng một trang thương mại điện tử chuyên nghiệp, giao diện mượt mà và xử lý toàn bộ nghiệp vụ bán hàng ở phía Front-end.

I. PHÂN TÍCH YÊU CẦU PHẦN MỀM

1.1. Giới thiệu đề tài

Trong kỷ nguyên số hiện nay, xu hướng mua sắm trực tuyến (E-commerce) ngày càng trở nên phổ biến, đặc biệt là trong lĩnh vực thiết bị số và phụ kiện công nghệ (chuột không dây, bàn phím cơ, tai nghe chống ồn, củ sạc GaN, cáp sạc nhanh, loa Bluetooth,...). Việc xây dựng hệ thống Website Bán Hàng Điện Tử TECHZONE nhằm tạo ra một kênh phân phối trực tuyến hiện đại, thân thiện, kết nối trực tiếp cửa hàng với người tiêu dùng. Hệ thống hỗ trợ khách hàng dễ dàng tìm kiếm, tham khảo thông số kỹ thuật và đặt mua nhanh chóng, đồng thời cung cấp công cụ trực quan hỗ trợ quản trị viên quản lý kho hàng và đơn hàng hiệu quả.

1.2. Mô tả bài toán

Hiện nay, việc bán lẻ thiết bị và phụ kiện điện tử còn tồn tại nhiều khó khăn nếu chỉ phụ thuộc vào cửa hàng vật lý hoặc các kênh bán hàng thủ công (tin nhắn mạng xã hội):

- Khó khăn cho khách hàng: Khách hàng khó tra cứu thông số kỹ thuật, so sánh giá cả, tình trạng còn hàng; không lưu giữ được giỏ hàng tiện lợi hoặc lịch sử đơn hàng để theo dõi tiến trình giao hàng.

- Khó khăn cho người quản lý: Dễ xảy ra sai sót khi chốt đơn, khó quản lý số lượng tồn kho theo thời gian thực, thiếu công cụ thống kê doanh thu, đơn hàng tập trung.

- Giải pháp: Xây dựng một website thương mại điện tử chuyên ngành đồ điện tử hoàn chỉnh với giao diện trực quan, logic xử lý mượt mà bằng JavaScript thuần (tìm kiếm, lọc danh mục, giỏ hàng, đặt hàng, quản trị sản phẩm & đơn hàng), giúp tự động hóa quy trình bán hàng và nâng cao trải nghiệm mua sắm của người dùng.

1.3. Phạm vi và mục tiêu hệ thống

Phạm vi hệ thống:

  • Áp dụng cho các cửa hàng, doanh nghiệp vừa và nhỏ kinh doanh thiết bị, phụ kiện điện tử.
  • Hệ thống tập trung vào việc giới thiệu sản phẩm, quản lý giỏ hàng, đặt hàng và quản trị bán hàng cơ bản dựa trên nền tảng Web Front-end với LocalStorage.
  • Chưa tích hợp cổng thanh toán trực tiếp từ cổng ngân hàng thực tế (VNPay/MoMo Sandbox) và dịch vụ vận chuyển bên thứ ba qua API bưu chính.

Mục tiêu hệ thống:

  • Quản lý tài khoản người dùng và phân quyền (Admin, Khách hàng).
  • Thêm, sửa, xóa và quản lý danh mục, sản phẩm điện tử (CRUD).
  • Tìm kiếm và lọc sản phẩm linh hoạt theo tên, danh mục và mức giá.
  • Hỗ trợ giỏ hàng, cập nhật số lượng realtime và tạo đơn hàng trực tuyến.
  • Quản lý tiến trình trạng thái đơn hàng (chờ xử lý, đang giao, đã giao, đã hủy).
  • Tích hợp banner chuyển động tự động và đồng hồ đếm ngược Flash Sale.
  • Thống kê trực quan số lượng sản phẩm, người dùng và tổng doanh thu.

Hệ thống phục vụ trực tiếp các nhóm tác nhân chính sau:

1.5. Yêu cầu phi chức năng (Non-functional Requirements)

  • Hiệu năng (Performance): Tốc độ tải trang dưới 2 giây; các thao tác lọc sản phẩm, tìm kiếm, cập nhật giỏ hàng phản hồi tức thì (< 100ms) không cần tải lại toàn bộ trang (Zero Reload).
  • Tính tương thích đa thiết bị (Responsive Web Design): Giao diện tự động co giãn tối ưu chuẩn xác trên Desktop (1920x1080), Laptop (1366x768), Tablet và Mobile (375px - 414px).
  • Tính tương thích trình duyệt (Cross-browser Compatibility): Chạy ổn định, không phát sinh lỗi script trên tất cả các trình duyệt phổ biến hiện nay (Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
  • Tính khả dụng & Trải nghiệm người dùng (UI/UX): Bố cục hiện đại, màu sắc chủ đạo xanh công nghệ (#007bff) kết hợp nền trắng thanh lịch, hiệu ứng hover mượt mà, thông báo Toast Notification rõ ràng khi thao tác giỏ hàng.
  • Tính toàn vẹn dữ liệu (Data Integrity): Sử dụng JSON serialization trên localStorage để lưu trữ lâu dài dữ liệu sản phẩm, đơn hàng và giỏ hàng ngay cả khi đóng hoặc làm mới trình duyệt.

2.2. Thiết kế cấu trúc dữ liệu lưu trữ (LocalStorage Database Schema)

Hệ thống sử dụng cơ chế Web Storage API (LocalStorage) để đóng vai trò như một cơ sở dữ liệu NoSQL dạng Key-Value phía máy khách (Client-side Database). Các bảng dữ liệu chính gồm:

Key LocalStorage Kiểu Dữ Liệu Cấu Trúc Các Trường (Schema Attributes)
techzone_products Array of Objects id, name, category, price, oldPrice, image, isHot, isNew, isSale, rating, stock, desc
techzone_users Array of Objects name, email, phone, password, role ('user' | 'admin')
techzone_cart Array of Objects id, name, price, image, quantity
techzone_orders Array of Objects id, customerName, phone, address, note, paymentMethod, items, total, date, status ('pending' | 'shipping' | 'done' | 'cancelled')
currentUser / techzone_current_user Object (hoặc null) name, email, phone, role ('user' | 'admin') (Phiên đăng nhập hiện tại)

IV. HIỆN THỰC CHỨC NĂNG, ỨNG DỤNG JS & GIẢI THÍCH CODE

4.1. Trang danh mục & Lọc sản phẩm thời gian thực (Yêu cầu 1)

Mô tả chức năng: Trang danh mục cho phép người dùng lọc sản phẩm theo từng nhóm (Chuột & Bàn phím, Cáp sạc, Âm thanh, Balo), lọc nhanh theo hàng Sale/Mới và sắp xếp theo mức giá tăng hoặc giảm dần mà không cần tải lại trang.

Đoạn code xử lý cốt lõi (js/products.js):

const applyFilters = () => {
    let filtered = [...products];

    // 1. Lọc theo từ khóa tìm kiếm (Live Search)
    if (initialSearch) {
        filtered = filtered.filter(p => p.name.toLowerCase().includes(initialSearch.toLowerCase()));
    }

    // 2. Lọc theo danh mục sản phẩm (Category Radio)
    const selectedCat = document.querySelector('input[name="cat"]:checked').value;
    if (selectedCat !== 'all') {
        filtered = filtered.filter(p => p.category === selectedCat);
    }

    // 3. Lọc theo trạng thái khuyến mãi / hàng mới
    if (filterSale.checked) filtered = filtered.filter(p => p.isSale);
    if (filterNew.checked) filtered = filtered.filter(p => p.isNew);

    // 4. Sắp xếp theo giá (Sort Price)
    const sortVal = sortSelect.value;
    if (sortVal === 'asc') filtered.sort((a, b) => a.price - b.price);
    else if (sortVal === 'desc') filtered.sort((a, b) => b.price - a.price);

    currentProducts = filtered;
    renderProducts(); // Xuất ra DOM
};

Giải thích giải thuật: Sử dụng cú pháp Spread Operator [...products] để nhân bản mảng gốc, sau đó lần lượt áp dụng phương thức bậc cao filter() kết hợp sort(). Hàm renderProducts() sử dụng phương thức map() để sinh mã HTML cho từng thẻ sản phẩm và gán vào innerHTML của lưới sản phẩm.

4.4. Form & Kiểm tra dữ liệu đăng ký bằng Regex (Yêu cầu 4)

Hình 4.2: Giao diện Form đăng ký tài khoản thành viên với cơ chế kiểm tra lỗi tự động

Đoạn code xử lý (js/auth.js):

const registerForm = document.getElementById('registerForm');
if (registerForm) {
    registerForm.addEventListener('submit', (e) => {
        e.preventDefault();
        let isValid = true;

        const name = document.getElementById('regName').value.trim();
        const email = document.getElementById('regEmail').value.trim();
        const phone = document.getElementById('regPhone').value.trim();
        const password = document.getElementById('regPassword').value;
        const passwordConfirm = document.getElementById('regPasswordConfirm').value;

        // 1. Kiểm tra rỗng họ tên
        if (name === '') {
            showError('errRegName', 'regName');
            isValid = false;
        }

        // 2. Kiểm tra định dạng Email bằng Regular Expression
        const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
        if (!emailRegex.test(email)) {
            showError('errRegEmail', 'regEmail');
            isValid = false;
        }

        // 3. Kiểm tra số điện thoại Việt Nam (10 số, đầu 03, 05, 07, 08, 09)
        const phoneRegex = /^(0|\+84)[35789][0-9]{8}$/;
        if (!phoneRegex.test(phone)) {
            showError('errRegPhone', 'regPhone');
            isValid = false;
        }

        // 4. Kiểm tra độ dài mật khẩu tối thiểu 6 ký tự
        if (password.length < 6) {
            showError('errRegPassword', 'regPassword');
            isValid = false;
        }

        // 5. Kiểm tra mật khẩu nhập lại trùng khớp
        if (password !== passwordConfirm || passwordConfirm === '') {
            showError('errRegPasswordConfirm', 'regPasswordConfirm');
            isValid = false;
        }

        // 6. Kiểm tra trùng lặp tài khoản trong localStorage
        if (isValid) {
            const users = JSON.parse(localStorage.getItem('techzone_users')) || [];
            if (users.find(u => u.email === email || u.phone === phone)) {
                alert('Email hoặc Số điện thoại này đã được đăng ký!');
                return;
            }

            // Lưu người dùng mới vào LocalStorage
            users.push({ name, email, phone, password, role: 'user' });
            localStorage.setItem('techzone_users', JSON.stringify(users));
            document.getElementById('regSuccessModal').classList.add('show');
        }
    });
}

Giải thích giải thuật: Sử dụng Regular Expression (Biểu thức chính quy) để kiểm tra tính hợp lệ của dữ liệu trước khi gửi lên hệ thống. Sử dụng emailRegex.test(email) để đảm bảo email có ký tự @ và tên miền hợp lệ. Sử dụng phoneRegex.test(phone) để kiểm tra chính xác đầu số nhà mạng viễn thông Việt Nam. Dùng users.find() để quét danh sách đã có trên LocalStorage nhằm ngăn chặn đăng ký trùng lặp.

4.5. Giỏ hàng & Lưu trữ LocalStorage (Yêu cầu 5)

Đoạn code xử lý (js/cart.js):

// 1. Lấy dữ liệu giỏ hàng từ LocalStorage
const getCart = () => {
    const cart = localStorage.getItem('techzone_cart');
    return cart ? JSON.parse(cart) : [];
};

// 2. Lưu giỏ hàng vào LocalStorage và cập nhật giao diện
const saveCart = (cart) => {
    localStorage.setItem('techzone_cart', JSON.stringify(cart));
    updateCartCount();
    if (typeof renderCart === 'function') renderCart();
};

// 3. Hàm Thêm sản phẩm vào giỏ
window.addToCart = (productId, quantity = 1) => {
    const product = products.find(p => p.id === productId);
    if (!product) return;

    let cart = getCart();
    // Kiểm tra xem sản phẩm đã có trong giỏ chưa
    const existingIndex = cart.findIndex(item => item.id === productId);
    if (existingIndex > -1) {
        cart[existingIndex].quantity += quantity; // Tăng số lượng nếu đã có
    } else {
        cart.push({
            id: product.id,
            name: product.name,
            price: product.price,
            image: product.image,
            quantity: quantity
        });
    }
    saveCart(cart);
    showToast(product); // Hiển thị popup thông báo
};

// 4. Cập nhật số lượng hiển thị trên Badge icon giỏ hàng Header
const updateCartCount = () => {
    const cart = getCart();
    const count = cart.reduce((total, item) => total + item.quantity, 0);
    const badge = document.getElementById('cartCount');
    if (badge) badge.innerText = count;
};

Giải thích giải thuật: Mảng giỏ hàng được tuần tự hóa bằng JSON.stringify và giải mã bằng JSON.parse. Phương thức findIndex() kiểm tra nhanh nếu sản phẩm đã tồn tại thì chỉ tăng thuộc tính quantity thay vì thêm dòng mới. Hàm reduce() cộng dồn toàn bộ số lượng để hiển thị lên icon giỏ hàng ở thanh điều hướng trên cùng.

4.6. Đồng hồ đếm ngược Flash Sale (Yêu cầu 6)

Hình 4.4: Khu vực Flash Sale với đồng hồ đếm ngược thời gian thực (Ngày : Giờ : Phút : Giây)

Đoạn code xử lý (js/slider.js):

// Thiết lập mốc thời gian kết thúc: 12 giờ 45 phút kể từ lúc mở trang
const endTime = new Date().getTime() + (12 * 60 * 60 * 1000 + 45 * 60 * 1000);

const timer = setInterval(() => {
    const now = new Date().getTime();
    const distance = endTime - now; // Khoảng thời gian chênh lệch (mili giây)

    if (distance < 0) {
        clearInterval(timer);
        document.getElementById('countdown').innerHTML = "<h3>ĐỢT SALE ĐÃ KẾT THÚC</h3>";
        return;
    }

    // Quy đổi từ mili giây sang Ngày, Giờ, Phút, Giây bằng toán tử chia dư (%)
    const days = Math.floor(distance / (1000 * 60 * 60 * 24));
    const hours = Math.floor((distance % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
    const minutes = Math.floor((distance % (1000 * 60 * 60)) / (1000 * 60));
    const seconds = Math.floor((distance % (1000 * 60)) / 1000);

    // Cập nhật lên DOM (dùng padStart để luôn có 2 chữ số: 05, 09,...)
    document.getElementById('days').innerText = days.toString().padStart(2, '0');
    document.getElementById('hours').innerText = hours.toString().padStart(2, '0');
    document.getElementById('minutes').innerText = minutes.toString().padStart(2, '0');
    document.getElementById('seconds').innerText = seconds.toString().padStart(2, '0');
}, 1000);

Giải thích giải thuật: Lấy mốc thời gian hiện tại now so với thời điểm kết thúc endTime bằng getTime() (tính bằng mili-giây). Sử dụng toán tử chia lấy dư % kết hợp Math.floor() để phân tách chính xác số Giờ, Phút, Giây. Phương thức padStart(2, '0') giúp số đơn lẻ (ví dụ: 7 giây) luôn được hiển thị thành 2 chữ số chuẩn điện tử: "07". Khi thời gian về 0, hàm clearInterval sẽ hủy vòng lặp và xuất thông báo kết thúc sale.

document.addEventListener('DOMContentLoaded', () => {

7.1. Đánh giá kết quả đạt được
